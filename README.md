# 🌊 Волна (Volna)

> **Ультралёгкий нативный плеер Яндекс Музыки для Linux на Rust и GTK4 / Libadwaita.**
> Разработан для решения проблемы избыточного потребления оперативной памяти официальным Electron-клиентом.

## 🎯 Зачем этот проект?

Официальный десктопный клиент Яндекс Музыки (как и большинство веб-обёрток) построен на базе **Electron** (Chromium + Node.js). В процессе воспроизведения он стабильно занимает **от 600 МБ до 1.5 ГБ оперативной памяти**, нагружает процессор фоновыми задачами рендеринга и медленно стартует.

**Волна** написана с нуля на **Rust** с нативным интерфейсом **GTK4 / Libadwaita**:
- 🚀 **Потребление RAM:** всего **~30–45 МБ** во время воспроизведения (в 20–30 раз меньше Electron).
- ⚡ **Старт приложения:** менее **0.1 секунды**.
- 🔋 **Энергоэффективность:** нулевая паразитная нагрузка на CPU и GPU в фоне — бережёт батарею ноутбука.
- 🎨 **Нативный визуал GNOME:** идеальная интеграция с Wayland, тёмной темой, системными шрифтами и жестами тачпада.
- ⌨️ **MPRIS2:** полное управление медиа-клавишами, интеграция с виджетами рабочего стола (Waybar, Quickshell) и экраном блокировки.

## ✨ Возможности

- [x] **Волна (Rotor):** бесконечный персональный поток рекомендаций с быстрой отправкой реакции (❤️ Лайк, 💔 Дизлайк, ⏭ Пропуск).
- [x] **Настройка Волны:** фильтры по настроению (бодрое, спокойное, радостное, грустное), характеру и языку (русский, иностранный, без слов).
- [x] **Коллекция и плейлисты:** доступ к трекам «Мне нравится», пользовательским и кураторским подборкам, альбомам.
- [x] **Поиск:** результаты по мере ввода (треки, артисты, альбомы, плейлисты), раздел «Все» показывает верх выдачи, **история поиска** хранит открытые результаты.
- [x] **Качество звука:** MP3 в максимальном битрейте, который Яндекс отдаёт сторонним клиентам (сейчас до 192 кбит/с; lossless недоступен). Реальный формат показывается в плеере, выбор качества есть в настройках.
- [x] **Повтор:** выключен / один трек / вся очередь (в Волне без «всей очереди»).
- [x] **Справка об исполнителе и альбоме:** краткий текст из Википедии, Last.fm и Genius (последние два нужны ключи в настройках) с кнопкой перевода английского текста на русский.
- [x] **Навигация:** клик по обложке в плеере открывает альбом, исполнитель и альбом в подписи страниц — ссылки.
- [x] **Бесшовный переход (Gapless / Preload):** автоматическая предварительная загрузка следующего трека для непрерывного звучания без задержек.
- [x] **Тексты песен (Lyrics):** просмотр текстов композиций с подсветкой текущих строк.

## 🏛 Архитектура проекта

Кодовая база спроектирована по модульному принципу с разделением интерфейса, звукового конвейера и сетевой логики:

- **`src/api/`** — Асинхронный клиент к Яндекс Музыке (`reqwest`, `serde`, `md-5`):
  - `client.rs` — генерация очереди треков станции `user:onyourwave`, расчет прямого URL через соленый MD5-хеш, отправка событий обратной связи (`trackStarted`, `trackFinished`, `skip`, `like`, `dislike`).
  - `models.rs` — строго типизированные структуры треков, артистов, альбомов и ротора.
  - `auth.rs` — токен авторизации, качество звука, ключи Genius и Last.fm (`~/.config/volna/config.json`).
  - `history.rs`, `wiki.rs`, `lastfm.rs`, `genius.rs`, `translate.rs` — история поиска, справка об артистах и альбомах, перевод.
- **`src/player/`** — Высокопроизводительный звуковой бэкенд на базе **GStreamer**:
  - `audio.rs` — потоковый плеер (`gstreamer-play`) с буферизацией в реальном времени без выгрузки всего файла в RAM.
  - `manager.rs` — менеджер очереди и событий обратной связи станции.
- **`src/ui/`** — Нативный интерфейс **Libadwaita / GTK4** по утвержденному концепту **«Wave-First & Fluid»**:
  - `wave_view.rs` — экран «Волна» с интерактивным органическим визуализатором волны (`DrawingArea` + Cairo), элементами фильтров потока и крупной кнопкой воспроизведения.
  - `floating_island.rs` — адаптивный парящий остров-плеер (`GtkOverlay`) со скруглением 24px, круглой обложкой, слайдером времени, реакциями и регулировкой громкости.
  - `search_view.rs` / `library_view.rs` — поиск и пользовательская медиатека.
  - `preferences_dialog.rs` — настройки: качество звука, токен Яндекса, ключи Genius и Last.fm, очистка кэша.
  - `collection.rs` — страницы альбомов, плейлистов, артистов и треков, плитки и карточка со справкой.
  - `style.css` — стилизация GNOME Dark, амбиентные радиальные градиенты и эффекты скруглений.

## 🛠 Сборка и запуск

### Системные зависимости (Arch Linux / Manjaro):
```bash
sudo pacman -S gtk4 libadwaita gstreamer gst-plugins-base gst-plugins-good gst-plugins-bad
```

### Сборка из исходников:
```bash
git clone https://github.com/fallkdm/volna.git
cd volna
cargo build --release
```

### Запуск:
```bash
./target/release/volna
```

Токен авторизации можно ввести через меню «Настройки» (`Preferences`) либо сохранить в `~/.config/volna/config.json`:
```json
{
  "token": "y0_AgAAAA..."
}
```

# 🌊 Волна (Volna)

> **Ультралёгкий нативный плеер Яндекс Музыки для Linux на Rust и GTK4 / Libadwaita.**
> Разработан для решения проблемы избыточного потребления оперативной памяти официальным Electron-клиентом.

## 🎯 Зачем этот проект?

Официальный десктопный клиент Яндекс Музыки (как и большинство веб-обёрток) построен на базе **Electron** (Chromium + Node.js). В процессе воспроизведения он стабильно занимает **от 600 МБ до 1.5 ГБ оперативной памяти**, нагружает процессор фоновыми задачами рендеринга и медленно стартует.

**Волна** написана с нуля на **Rust** с нативным интерфейсом **GTK4 / Libadwaita**:
- 🚀 **Потребление RAM:** всего **~30–45 МБ** во время воспроизведения (в 20–30 раз меньше Electron).
- ⚡ **Старт приложения:** менее **0.1 секунды**.
- 🔋 **Энергоэффективность:** нулевая паразитная нагрузка на CPU и GPU в фоне — бережёт батарею ноутбука.
- 🎨 **Нативный визуал GNOME:** идеальная интеграция с Wayland, тёмной темой, системными шрифтами и жестами тачпада.
- ⌨️ **MPRIS2:** полное управление медиа-клавишами, интеграция с виджетами рабочего стола (Waybar, Quickshell) и экраном блокировки.

## ✨ Возможности

- [x] **Моя волна (Rotor):** бесконечный персональный поток рекомендаций с быстрой отправкой реакции (❤️ Лайк, 💔 Дизлайк, ⏭ Пропуск).
- [x] **Настройка Волны:** фильтры по настроению (бодрое, спокойное, радостное, грустное), характеру и языку (русский, иностранный, без слов).
- [x] **Коллекция и плейлисты:** доступ к трекам «Мне нравится», пользовательским и кураторским подборкам, альбомам.
- [x] **Поиск:** мгновенный поиск по трекам, артистам и альбомам.
- [x] **Аудио высокой чёткости:** стриминг в высоком битрейте (MP3 320 kbps / FLAC Lossless при наличии подписки Плюс).
- [x] **Бесшовный переход (Gapless / Preload):** автоматическая предварительная загрузка следующего трека для непрерывного звучания без задержек.
- [x] **Тексты песен (Lyrics):** просмотр текстов композиций с подсветкой текущих строк.

## 🛠 Сборка и запуск

### Зависимости (Arch Linux / Manjaro):
```bash
sudo pacman -S gtk4 libadwaita gstreamer gst-plugins-base gst-plugins-good gst-plugins-bad
```

### Сборка из исходников:
```bash
git clone https://github.com/fallkdm/volna.git
cd volna
cargo build --release
```

### Запуск:
```bash
cargo run --release
```
